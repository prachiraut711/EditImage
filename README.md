# 🖼️ EditImage – AI Image Editing Web Application

EditImage is a web-based application that allows users to upload and edit images using simple and intuitive tools. The application provides basic image processing functionalities through a clean and user-friendly interface.

---

## 🚀 Features

- 📤 Image Upload – Upload images directly from your device  
- ✂️ Image Editing – Perform basic image modifications  
- 🎨 Filters & Enhancements – Apply visual effects and enhancements  
- 💾 Download Image – Save edited images locally  
- 🖥️ User-Friendly UI – Clean and responsive interface  

---

## 🛠️ Tech Stack

### 💻 Backend
- Python  
- Flask  

### 🌐 Frontend
- HTML  
- CSS  
- JavaScript  

### 📦 Libraries
- OpenCV / PIL  
- NumPy  

---

## 🧠 How It Works

1. Upload an image  
2. Image is sent to Flask backend  
3. Processing operations are applied  
4. Output is displayed on UI  
5. Download the edited image

## ⚙️ Installation & Setup

1. Clone repository  
git clone https://github.com/prachiraut711/EditImage.git  
cd EditImage  

2. Create virtual environment  
python -m venv venv  
venv\Scripts\activate  

3. Install dependencies  
pip install -r requirements.txt  

4. Run the app  
python app.py  

5. Open in browser  
http://127.0.0.1:5000
